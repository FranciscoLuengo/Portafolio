Bienvenido a mi portafolio profesional. Este proyecto está diseñado para mostrar mis habilidades, experiencia y proyectos destacados en el desarrollo web, construido con las tecnologías más modernas para garantizar rendimiento y diseño de alta calidad.

## 🚀 Características

- **⚡ Rendimiento Máximo**: Construido con [Astro](https://astro.build/) para una velocidad de carga excepcional.
- **🎨 Diseño Premium**: Estilizado con [Tailwind CSS v4](https://tailwindcss.com/) utilizando Glassmorphism y efectos visuales modernos.
- **📱 Totalmente Responsive**: Adaptado perfectamente a móviles, tablets y escritorio.
- **✨ Carrusel Interactivo**: Sección de tecnologías con scroll infinito y respuesta táctil, impulsado por [Swiper.js](https://swiperjs.com/).
- **🌑 Modo Oscuro Nativo**: Temática oscura elegante y profesional.

## 🛠️ Tecnologías Utilizadas

- **Core**: Astro 5
- **Estilos**: Tailwind CSS 4
- **Interactividad**: JavaScript / TypeScript
- **Carousel**: Swiper.js
- **Iconos**: SVGs optimizados

## 📂 Estructura del Proyecto

El portafolio consta de las siguientes secciones principales:

- **Inicio (Hero)**: Introducción impactante.
- **Tecnologías**: Carrusel interactivo con mis herramientas principales (React, Angular, Node.js, etc.).
- **Proyectos**: Galería de trabajos realizados.
- **Sobre Mí**: Resumen de mi trayectoria.
- **Contacto**: Formas de conectar conmigo.
